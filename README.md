# MCP Servers

Collection of [MCP (Model Context Protocol)](https://modelcontextprotocol.io/) servers for local LLM use.

Each server lives in its own directory with its own setup instructions.

## Servers

| Server | Description |
|--------|-------------|
| [searxng](searxng/) | Web search via SearXNG |

See the README in each server's directory for setup and usage details.
